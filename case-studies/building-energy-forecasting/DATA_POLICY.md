# Data Policy

This repository is a public, anonymized portfolio case study.

## Excluded from publication

- raw building electricity measurements;
- weather workbooks received with the original task;
- hourly target observations and prediction tables;
- submission CSV/XLSX files;
- original notebooks and rendered reports;
- building identifiers, addresses, floor-area records, and operational metadata;
- supervisor names, email content, and institutional correspondence;
- private file names or paths that could identify the source project.

## Included

- a high-level description of the forecasting problem;
- a generic implementation outline without private schema names;
- rounded aggregate benchmark metrics;
- limitations, validation design, and data-governance notes.

The case study must not be used to infer the energy profile of any real building. Any reproduction should use synthetic or explicitly permissioned, de-identified data.
